THE METHOD

Three redundancies.
One focused pipeline.

Instead of asking a large language model to do everything, HyFunc separates understanding, function retrieval, and parameter generation.

01 / UNDERSTAND

Compress the intent.

A large model distills user intent into a single soft token, avoiding repeated processing of a full library of function descriptions.

02 / RETRIEVE & DELEGATE

Use the right model.

A dual-encoder retriever selects relevant functions. The projected soft token conditions a smaller, prefix-tuned model.

03 / GENERATE

Skip the boilerplate.

Dynamic templating injects fixed parameter syntax on the fly, focusing model generation on the values that actually change.

DYNAMIC TEMPLATING

Predict the values.
Not the punctuation.

Function names, parameter keys, and fixed syntax do not need to be rediscovered at every token. Templates supply the structure; the small model concentrates on request-specific parameter values.

RESEARCH NOTES

A clearer picture,
before you begin.

What the method does, what the public code includes, and what reproduction requires.

How does HyFunc accelerate LLM function calling?

HyFunc reduces three sources of redundancy: processing full function descriptions repeatedly, using a large model for full-sequence generation, and generating fixed parameter syntax token by token. A shared soft token supports function retrieval and small-model conditioning; dynamic templating supplies boilerplate syntax.

Does HyFunc use vLLM or Transformers?

The paper describes dynamic templating within an extended vLLM engine. The public codes/dynamic_templating.py example uses Transformers; it does not include that vLLM engine extension and uses true_func_info annotations to construct templates.

Can I directly reproduce the paper's BFCL results?

Not as a one-command workflow. Example paths reference BFCL v3, while the included evaluator has BFCL v4 data. Prepare matching question/answer files and align the retriever's functions result key with the inference example's function key. Configure checkpoint paths, model dimensions, and hardware; download models and data separately. No validated HyFunc dependency lockfile is provided, and the annotated inference example is not annotation-free end-to-end deployment. See the full reproduction limits.

What should I know before using or sharing the code?

This is research code for efficient LLM tool calling, not a packaged agent framework or hosted inference service. No root-level HyFunc license is currently present; confirm reuse permissions with the maintainers. Cite the paper when using the method, code, or findings in research, and credit upstream models, datasets, and Gorilla/BFCL resources independently.
