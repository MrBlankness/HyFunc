HyFunc: Accelerating LLM-based Function Calls for Agentic AI through Hybrid-Model Cascade and Dynamic Templating

Weibin Liao, Jian-Guang Lou, and Haoyi Xiong
Proceedings of the 32nd ACM SIGKDD Conference on Knowledge Discovery and Data Mining V.1, 2026, pages 819-830. DOI: 10.1145/3770854.3780283.

HyFunc reduces redundant computation in LLM-based tool calling. A large model provides a soft-token representation of user intent for function retrieval and small-model conditioning. Dynamic templating avoids generating fixed parameter syntax token by token.

The paper reports 0.828 seconds inference latency and 80.1% accuracy in its evaluation configuration. These are paper-reported results, not guarantees for other hardware, models, workloads, or benchmark versions.

When to use HyFunc

Explore this code for research on efficient LLM function calling, low-latency tool selection, soft-token conditioning, hybrid-model cascades, and Berkeley Function Calling Leaderboard (BFCL) evaluation. Compare its requirements with your task before selecting it.

Start with the setup and research workflow. The implementation stages are large-model embedding extraction, function retrieval, small-model training, and template-guided inference.

Research-code limitations: run scripts from codes/ with separately downloaded models and datasets. No validated HyFunc dependency lockfile is provided. The examples reference BFCL v3 while the included evaluator has v4 data; retriever/inference result keys and checkpoint paths need alignment. The inference example uses annotated templates. The public example uses Transformers, not the paper's extended vLLM engine. This is not a turnkey agent SDK, MCP server, or hosted API.
